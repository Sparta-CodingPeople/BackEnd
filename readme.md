## 📢 프로젝트 소개

최근 배달 시장은 성장 정체를 넘어 다시 활성화되고 있으며, 2024년 배달 거래액은 사상 최대치인 27조~28조 원에 이를 것으로 예상됩니다. 이러한 변화 속에서 보다 효율적인 주문 및 배달 관리 시스템의 필요성이
더욱 강조되고 있습니다.
본 프로젝트는 배달 및 포장 주문을 효율적으로 관리하는 플랫폼 개발을 목표로 합니다.
사용자는 앱을 통해 간편하게 음식을 주문할 수 있으며, 주문은 실시간으로 배달 시스템과 연동되어 신속하게 처리됩니다.
오직 실제 주문한 사용자만 리뷰를 작성할 수 있도록 하여 신뢰도를 높이고, 투명한 운영 환경을 조성하였습니다.

### 🎯 주요 기능

- **공통 기능**
    - 회원가입
        - 사업자는 `사업자번호`를 필요로 한다.
    - 로그인
        - 관리자는 `마스터 코드`를 필요로 한다.
        - 로그인 성공 시 발급시간 기준으로 유저에게 토큰 발급시간이 등록된다.
    - 인증 및 인가
        - 인증이 필요한 요청은 유저의 토큰 발급시간 이후의 토큰을 갖고 있는지 검증 과정을 거친다.
        - 토큰이 만료된 경우 갱신 요청을 통해 발급 시간을 업데이트한다.
        - 각 요청마다 지정된 권한을 갖고있는 유저만 정상적인 요청이 가능하다.

- **사용자(고객)**
    - 회원 `정보 수정, 삭제, 조회`
    - 회원 `검색`
    - 매장 `검색 / 조회`
        - 관리자에 의해 승인된 매장만 확인이 가능하다.
        - 매장 `위치 , 매장 운영 시간 및 현재 영업 여부, 휴일 정보` 확인
    - 메뉴 `검색 / 조회`
        - 메뉴 노출 여부가 가능인 상품만 조회 및 검색이 가능하다.
    - 장바구니 `조회 / 메뉴 담기 / 메뉴 비우기 / 조회`
        - **장바구니에 다른 메뉴가 있다면 상품을 담을 수 없다.**
    - 주문 `요청`
    - 결제 `요청 / 취소 / 조회 / 검색`
        - 본인의 결제 내역만 조회 및 검색이 가능하다.
        - 주문이 취소 및 거절된 경우에 취소가 가능하다.
    - 리뷰 `등록 / 수정 / 조회`
        - 등록한 리뷰는 삭제할 수 없다.
        - 등록한 리뷰는 일정 기간동안 수정이 가능하다.
    - 배달 `조회`

- **사용자(사장)**
    - 매니저 `채용`
    - 매니저 `변경`
        - 매장 `정보 수정 / 위치 수정 / 운영 시간 수정`
        - 매장 `삭제`
        - 메뉴 `등록 / 수정 / 삭제 / 조회 / 검색`
        - 주문에 메뉴가 포함 될 경우 메뉴를 삭제할 수 없다.
            - 주문 `접수 / 승인 / 거절 / 취소/ 조회`
        - 주문이 `승인`된 상태에서는 거절 및 취소를 할 수 없다.
            - 주문이 `배달중`인 상태에서는 거절 및 취소를 할 수 없다.
            - 본인 매장에 대한 주문만 조회가 가능하다.
        - 배달 `상태 변경`
            - 주문에 대한 상태를 배달중으로 변경할 수 있다.
        - 리뷰 `조회`
            - 본인 매장에 대한 조회만 가능하다.
- **사용자(매니저)**
    - 메뉴 `등록 / 수정 / 삭제`

- **관리자**
    - 입점 `요청 조회 / 승인`
    - 사용자의 `모든 권한`을 포함하고 있다.
    - 결제 `수정`
    - 리뷰 `수정 및 삭제`
